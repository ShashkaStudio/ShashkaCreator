# ShashkaCreator
ShashkaCreator is open source C++ library for creating 2D games and applications on Windows. The library is written using the standard WinAPI libraries in Codeblocks and consists of several modules. 
Shashka Creator — это библиотека с открытым исходным кодом на C++ для создания 2D игр и приложений под Windows. Библиотека написана с использованием стандартных библиотек WinAPI из Codeblocks и состоит из нескольких модулей.
